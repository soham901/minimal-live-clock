# Roadmap

This is a pet project, so none of this is a promise. It's a list of ideas, roughly in the order I'd do them.

## Next

- [ ] 24-hour time, plus date format and locale settings
- [ ] BRB countdown ("back in 10:00") and "back at 7:30 PM"
- [ ] Settings in the URL (`?ring=day&seconds=1`) so a setup can be bookmarked
- [ ] Transparent background mode for OBS and stream overlays
- [ ] Screen wake lock, so the display doesn't sleep while the clock is up

## Then

- [ ] Extension icon and a Chrome Web Store listing
- [ ] A second time zone
- [ ] Focus timer that uses the ring as its progress display
- [ ] Light theme and a font picker (monochrome stays the default)
- [ ] OLED burn-in guard: tiny slow drift and auto-dim at night
- [ ] Offline fonts bundled with the extension

## Later

- [ ] Sunrise and sunset for the part-of-day ring instead of fixed 6-hour blocks
- [ ] Optional chime on the hour or when a timer ends
- [ ] Next calendar event under the time
- [ ] Desktop app or screensaver build
